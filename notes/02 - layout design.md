> [!success] Layout
> **Redox minus its inner column**: 66 keys, QWERTY, 1.25u outer columns, a Kinesis-style extra bottom row with `[` `]` on the right, and the Redox thumb cluster (2×2 block: two 1u over two 1.25u at 30°, plus one 1.25u). Arrows are on **HJKL** behind a layer key. An EC11 knob sits in the freed space on each half's inner edge, mirrored, with an OLED above it. Geometry comes from `redox-layout.json` (mattdibi/redox-keyboard, MIT), placed in KiCad with KB Placer. Full keymap: [[12 - final design#Layout]].

## Key layout

### Layout type
- **Column-staggered**: columns offset to match finger lengths
- **Split**: two halves at shoulder width

### Key count
- **66 keys total** (33 per half): 52 × 1u, 14 × 1.25u
- Thumb cluster: 5 per side (2×2 block + one 1.25u)
- One rotary encoder per half; each push switch is in its half's matrix, so the keymap has 68 positions (both knob presses sit in the middle of the number row)

### Base
**Redox** by Mattia Dal Ben: a flat, 7×5 columnar split derived from the Ergodox.
- GitHub: [mattdibi/redox-keyboard](https://github.com/mattdibi/redox-keyboard) (MIT)
- Key coordinates come from its `img/redox-layout.json`; the copper is redrawn

Every key in the 2×2 thumb block is at most one step from where the thumb rests, which suits small hands.

## Tools

- **KB Placer** (KiCad plugin): places the switch footprints from `redox-layout.json`
- **Keyboard Layout Editor (KLE)** JSON: the source for the ZMK Studio physical layout, generated by `tools/gen_zmk_layout.py`
- **Paper fit test**: [`keygen-plate-print.pdf`](https://github.com/milindmadhukar/keygen/releases/download/build/keygen-plate-print.pdf) prints the switch plate at 1:1 on A4, one half per page

## Layers

Blank keycaps fix only the letters, so everything else is placed by layer:

- **Base**: QWERTY with a number row (Hyprland uses Super + number for workspaces), brackets on the extra row, Esc that holds as Ctrl, Caps Word
- **Nav** (left 1.25u): arrows on HJKL, Home/End/PgUp/PgDn, one-hand modifiers
- **Fn** (right 1.25u): F-keys, numpad, media, Caps Lock
- **System** (both): Bluetooth profiles, output selection, LED controls, bootloader
- **Knobs:** the left one scrolls on every layer (with Super held it walks Hyprland's workspaces; press: middle click); the right one is volume on Base (press: mute), Page Down / Page Up on Nav and screen brightness on Fn (press: play/pause)

Details: [[12 - final design#Nav, Fn and System layers]] and [[12 - final design#Knobs]].
