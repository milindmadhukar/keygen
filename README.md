# Keygen

A one-off wireless split keyboard: a fork of the [Redox](https://github.com/mattdibi/redox-keyboard)
key layout with a knob, OLED, Cirque trackpad and per-key RGB, on two nRF52840 controllers
running ZMK (Bluetooth or USB to the host, Bluetooth or TRRS between halves).

- `plan/index.html` — the build plan: layout, wireless/wired architecture, parts, pin budget,
  firmware notes, build steps, references. Open it in a browser.
- `notes/` — symlink to the project notes in the Obsidian vault
  (`~/Documents/Obsidian Vault/01 - Projects/Hardware & Electronics/Keygen Custom Keyboard`).
  It only resolves on this machine.
