# Ordering the Keygen PCBs (bare boards, self-assembly)

Place **two orders**: `keygen-left-gerbers.zip` and `keygen-right-gerbers.zip`, 5 of each.
Per half came out cheaper at Lion Circuits than the combined file (checked 2026-10-20).
`keygen-gerbers.zip` (both halves in one design) is kept for fabs that price it better.

| Setting | Value |
|---|---|
| Layers | 2 |
| Material | FR-4, 1.6 mm |
| Copper | 1 oz (35 µm) |
| Board size | both halves: 363.0 × 125.9 mm · one half: 162.7 × 125.9 mm |
| Quantity | 5 left + 5 right (two orders) |
| Surface finish | HASL lead-free (cheapest; fine for hand soldering) |
| Soldermask / silkscreen | any colour (green + white is cheapest) |
| Min track / clearance | 0.15 mm / 0.2 mm (6/8 mil) |
| Min hole | 0.3 mm (vias); no blind/buried vias |
| Assembly | none (bare boards) |
| Stencil | not needed |

**Things to tell the fab or check in their DFM report**
- Each half has 33 small internal rectangular cut-outs (reverse-mount LED windows, about
  3.5 × 3.2 mm, with corner reliefs). They are on the Edge.Cuts layer and must be routed (milled).
- LED pads sit about 0.25 mm from those cut-outs (copper-to-edge 0.2 mm).
- The USB-C end of each controller overhangs the board edge by 1 mm on purpose (no copper there).

Generated by `tools/export_fab.py` from `pcb/keygen.kicad_pcb`.
Files in each zip: keygen-B_Cu.gbl, keygen-B_Mask.gbs, keygen-B_Silkscreen.gbo, keygen-Edge_Cuts.gm1, keygen-F_Cu.gtl, keygen-F_Mask.gts, keygen-F_Silkscreen.gto, keygen-NPTH-drl_map.gbr, keygen-NPTH.drl, keygen-PTH-drl_map.gbr, keygen-PTH.drl, keygen-job.gbrjob
